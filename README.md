# Pawn Vault Landing Page

A modern, responsive landing page for the Pawn Vault Android app built with React and Material UI.

## Getting Started

1. Install dependencies:
   - `npm install`
2. Start the dev server:
   - `npm start`

## Notes

- Replace `public/pawnvault2.apk` with the real APK.
